# WanderLanka Travel Website

A responsive static travel website built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` - main page
- `css/style.css` - responsive styling
- `js/script.js` - mobile menu, year and contact form interaction

## Deploy
Upload the project to any static host. It works with GitHub Pages, Netlify, Vercel static hosting, or regular web hosting.

The site uses remote Unsplash images and Google Fonts, so an internet connection is needed for those assets. Replace the image URLs with local images if you want a fully self-contained/offline site.
